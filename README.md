### 🏗️ Engineering Highlights

How I approach the parts of a system that decide whether it survives production:

- **Multi-tenant SaaS** — tenant scoping enforced at the data layer, not just the UI
- **Authorization** — RBAC with roles and permissions modelled in the schema
- **Modular backends** — NestJS modules with clear domain boundaries and DI
- **Schema design** — normalized PostgreSQL schemas, indexed for real query patterns
- **Type safety** — TypeScript from database models through API contracts to components
- **Real-time** — WebSocket channels for live data without polling
- **AI systems** — retrieval pipelines that ground LLM output in trusted sources
- **Delivery** — Dockerized services, GitHub Actions CI/CD, environment-based configuration
